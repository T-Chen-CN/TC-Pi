# 工作台使用指南

本指南适用于当前精简版本，功能总表见 [功能参考](./feature-reference.md)。

## 工作区与布局

左侧保留主界面、独立聊天、工作区选择及可展开的文件管理。添加工作区通过文件夹选择窗口完成；工作区列表在左侧向下展开。

中间显示文件预览或编辑页面，右侧会话区始终存在。会话选择在会话标签工具行的下拉窗口中完成，加号直接为当前工作区创建会话。不同工作区的会话不混在同一个会话栏。

工具侧栏默认隐藏，可用于 Git、终端、浏览器和扩展面板。切换工作区保留窗口布局；有忙碌 Agent 时需确认终止后才能切换，空闲时直接切换。

## 文件与会话

展开文件管理后，可以浏览当前工作区、搜索和刷新目录，并打开文件标签页。文件能否预览或编辑由文件类型、内容和大小决定。

当前 Pi 会话支持流式回复、工具调用、提问审批、计划、目标、子代理和待办展示。模型供应商、模型与思考档位通过输入栏和设置管理。会话列表按创建时间固定倒序；更新回复不会改变顺序。

主界面显示工作区、历史会话、Token 和费用概览，以及最近会话。

## 开发工具与资源

Git 面板支持变更、暂存、提交、分支、提交图和差异查看。终端与浏览器在工作区工具中打开。本地提示词、Skills、Pi 扩展、MCP 与宿主插件分别通过资源和设置页面管理。

定时任务入口位于左侧底部。任务只使用 Pi，可配置普通、计划或目标模式，并设置运行预算。本机 Web 服务用于远程会话浏览。

PiDeck 弃用功能二次清理
日期：2026-10-11
状态：代码清理及本机最终验证完成；用户授权本轮提交并合入本地 main，不推送远端。
基线：main / 74e6a5a0。关于面板修复也包含在本次清理中。

本轮处理结果
1. 自动化旧后端防护
   在手动运行、入队、旧队列消费和后台 cron 调度处拦截弃用后端。
   旧任务保留原后端身份，可查看/删除，不能运行、启用、保存或隐式转换为 Pi。
   拦截发生在创建运行和草稿之前，不再生成反复失败的旧后端草稿。
   自动化新任务只使用 Pi，删除 DSH 权限与发送分支以及单选后端控件。
   模式标记纯协议迁至 shared/promptSubmission.ts，主进程不再引用 renderer。

2. 配置与设置清理
   删除 ConfigModal 的 DSH 顶层分页、记忆、脏状态、供应商排序和保存聚合逻辑。
   删除 im/pet/vision/imagegen/acp 导航类型、图标/关键词、未保存摘要登记和无消费者 atom。
   Pi 模型、认证、配置保存、MCP、安全、本地技能/提示词/扩展不受影响。

3. 匿名会话和旧运行时入口
   删除 bindAnonymousRuntime、registerPendingRuntime 和零写入的 transientEntries 路径。
   删除匿名关闭确认、头部徽章/样式及专用历史编辑/重发分支。
   主进程拒绝 noSession=true 的聊天激活与创建，保留普通草稿首次发送失败的重试。
   PiModelCapabilityCache 的 --no-session 仅用于隔离的模型目录探测，继续保留。
   历史标记仍可读取，不清用户文件，也不将旧记录重写成 Pi。

4. 历史交互边界
   弃用后端历史隐藏编辑、删除消息、重发、分支、回退、复制会话和导出操作。
   历史消息修改 hook 再次防御，不能靠旧记录的 backend 触发普通 Pi 发送。
   正常 Pi 的分支编辑、重发、离线删除和确定失败提示保留；未知投递不宣称失败。
   历史不可用时不再显示“启动 DSH host 即可恢复”的误导提示。

5. 当前跨层契约
   关于面板、AppInfo 不再展示 DSH runtime 版本。
   用量探针 IPC/preload/共享类型只接受 Pi，旧后端参数明确拒绝，不隐式映射。
   TokenDance 回传删除 dshSaved/dshWroteViaHost/dshError，仅保存 Pi 配置。
   删除当前网关 DSH 权限操作、飞书设置重置回调和无人使用的 DSH 日志广播器。
   正常 Pi 实时日志仍由 AgentManager 提供，RPC 日志面板和订阅继续保留。

6. 在线商店和文案
   删除恒 false 的推荐扩展包面板、在线推荐列表、安装回调和唯一专用类型 PiPackageInfo。
   删除中文提示词库的残留分类样式以及无消费者的 DSH 命令建议。
   对弃用命名空间先核对生产引用，再清简中/英文并生成繁中；保留历史读取所需文案。
   本地资源安装/管理、内置扩展本身、GUI 桥和内容覆盖层更新继续保留。

7. 维护和打包
   删除 dump-typert-endpoints、pwsh-persistent-smoke、local-package-build、旧 CUA 实施计划。
   消息测试脚本改用现成 TS helper，已实际执行通过。
   asar 根集合和校验改为当前 Pi 主进程依赖，不再要求飞书/koffi/DSH 闭包。
   AtomGit 资产分类删除 DSH runtime/runner；遥测删除固定 false/0 的已弃用功能字段。
   Linux 不再接收 petEnabled，默认保留原生显示后端，用户显式 x11 设置仍有效。
   同步旧注释和失效测试，仅移除专门测试弃用能力的用例；Pi 和兼容读取回归保留。
   对触达模块做 AST 检查并清除 18 个无引用导入，相关设置/配置死状态一并移除。

保留边界
- 旧设置、session catalog 后端/身份/来源、删除墓碑以及历史消息解析仍作兼容读取。
- legacyImages 只读旧附件；正常 Pi 图片输入和模型原生视觉能力保留。
- Pi GUI 桥、模型追踪、语音、自动化、Git、终端、浏览器、Web、本地资源、宿主插件保留。
- Pi 扩展里的 acp-delegate 是委托协议，不是桌面 ACP 后端，未删除。
- 内置内容更新只注入编译时入口，不将 Store 命名的覆盖层管理误删为在线商店。
- 用户实际会话、密钥、设置、自装资源、运行中的 Agent 和 node_modules 未清理。
- 上游历史发布说明和合法通用组件不按关键词一刀切删除。

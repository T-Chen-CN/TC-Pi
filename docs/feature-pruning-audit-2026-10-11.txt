实施对照
1. DSH / ACP
   删除失效的操作 IPC、preload/API、后端切换、运行时安装/搜索/配置/模型操作、
   工具与权限面板、目标/团队/队列分支、Jotai 状态和孤立辅助模块。
   删除 sessionIpc/systemIpc 的旧后端依赖注入和不可达操作分支。
   Pi 的会话生命周期、模型/权限/运行设置、运行时身份校验与日志订阅保留。
   旧 DSH/ACP 会话保持身份；激活、发送和重启在创建运行时前拒绝，不清空草稿。

2. 独立图片生成 / 视觉桥
   删除独立生图配置和发送分支、专用状态、视觉桥失效 API、恒 false hook、
   运行时探测和轮询，以及只服务旧功能的布局测试和测试种子。
   保留历史图片附件、必要元数据与旧消息块解析/显示。
   普通图片输入、Pi 模型原生视觉能力和 GUI 扩展桥属于保留能力。

3. 飞书 / 桌宠 / 悬浮小窗 / CUA
   删除飞书进程参数、环境标记、问答禁用分支、专用样式和旧测试种子。
   将仍在使用的草稿本契约迁到 shared/types/scratchPad.ts。
   删除桌宠 CI 断裂作业、桌宠素材和引用已删除 CUA 源码的专用测试。
   不删除通用 MCP 中的 Lark 模板、正常浮层定位工具或系统置顶层级。

4. 在线商店与旧资源
   删除中文提示词数据库 resources/xueprompts.db、旧 DSH runtime 占位、
   ACP 手工联调脚本和旧 DSH 打包裁剪脚本。
   本地提示词/Skills/pi 扩展、用户自装资源、宿主插件和内置内容更新保留。
   在线浏览/安装商店的弃用协议和文案清除，不把本地资源管理误删为商店。

5. 导航与布局旧实现
   删除已被新工作台替代的 ProjectTree / SessionTree / WorktreeTree、
   SidebarRemovalRow、EditorSurface、ChatDirectoryButton、OutlinePanel、
   旧布局策略、旧会话排序选项及仅服务这些实现的测试。
   现有文件树、工作区选择、会话下拉、固定创建时间排序、Worktree、
   置顶/子会话、新建会话和窗口级布局状态保留。

6. 供应商与用量
   将 providerMigration.ts 中仍被 Pi 使用的解析、合并和目录快照函数
   拆到 piProviderConfig.ts，删除 Pi/DSH 互迁与 YAML/凭据映射代码。
   UsageStatsService 收口为 Pi 来源，删除 DSH bill-log 解析与来源合并。
   新增实际启动 hook 的复现测试：清理前仍会预热 DSH 配置，清理后只查询 Pi；
   旧 DSH 用量缓存不会触发后台查询。
   删除 js-yaml / @types/js-yaml 的直接依赖；锁文件保留构建/文档依赖所需的传递依赖。
   普通 Pi 供应商配置、认证、目录、模型缓存和用量探针保留。
   收尾删除仅由旧测试引用的 DSH 共享 host 代理聚合/环境补丁，以及不可达的用量配置回退。
   Pi 的会话代理覆盖、模型/供应商名单和 NODE_USE_ENV_PROXY 环境注入保留并回归验证。

7. 文案、说明和维护规则
